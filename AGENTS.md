# Agent Instructions — landing-au

## This is Next.js 16, not standard Next.js

This repo runs **Next.js 16.2.6** with **React 19.2.4**. APIs, conventions, and file structure differ from training data. Before writing any Next.js code, read the relevant guide in `node_modules/next/dist/docs/` and heed deprecation notices.

## Stack & Toolchain

- **Next.js 16.2.6** · App Router · TypeScript strict (`strict: true`)
- **React 19.2.4**
- **Tailwind CSS v4** — CSS-first with `@theme inline` in `globals.css`. **No `tailwind.config.ts` exists.** PostCSS plugin is `@tailwindcss/postcss`.
- **Anime.js v4** — sole animation engine. No Framer Motion. All animations must respect `prefers-reduced-motion` via `useReducedMotion()` hook.
- **Geist** — `geist/font/sans` and `geist/font/mono` loaded via `next/font` in `layout.tsx`.
- **No shadcn/ui** — components are 100% custom.

## Architecture

- Single-page landing (`/`). No dynamic routes.
- **Server Components by default** — all `app/sections/*` are Server Components. No `'use client'` in them.
- **Client Components only where needed** — `app/components/animation/*`, `StickyCTA`, and `FAQ` (accordion state). Mark with `'use client'`.
- `app/page.tsx` composes sections and injects JSON-LD schema.
- `app/layout.tsx` sets metadata (SEO, OG, Twitter, viewport) and loads Geist fonts.
- Data lives in `app/data/*` (products, stack, useCases, faq, socialProof). Types in `app/types/index.ts`.
- `app/lib/animations.ts` holds shared easings, durations, and stagger constants. `app/lib/utils.ts` is `cn()` from `clsx` + `tailwind-merge`.
- Path alias: `@/*` → `./*`

## Design Tokens

- Dark mode only (`#0A0A0B` background). No light-mode toggle.
- Single accent: `#FF0033` (red). No gradients, no purple/cyan.
- Fonts: Geist Sans (display + body), Geist Mono (labels, metrics, code).
- Animation properties limited to `transform` + `opacity` only (GPU layer). No `width/height/top/left/margin/padding` animations.

## Anime.js Rules

- Use `animejs` v4 (`import anime from "animejs"`).
- Always check `useReducedMotion()` before creating animations. If true, skip to final state (duration 0).
- Never leave `autoplay: true` without cleanup in React. Use `useEffect` cleanup to pause/destroy instances.
- All anime.js instances must be finite; no infinite loops unless explicitly justified (e.g. glow pulse).
